# 前端数据采集 SDK 功能清单（V1）

本文用于跟踪 V1 能力范围、默认状态、优先级、验收标准和风险等级。

## 1. 优先级定义

| 优先级 | 含义 |
| --- | --- |
| P0 | MVP 必须完成，否则 SDK 无法形成基础闭环。 |
| P1 | V1 建议完成，能显著提升可用性或覆盖核心场景。 |
| P2 | 可延后，适合 V1 稳定后再做。 |

## 2. 核心能力

| 功能 | 优先级 | 默认状态 | 验收标准 | 风险 |
| --- | --- | --- | --- | --- |
| SDK 初始化 | P0 | 开启 | `sdk.init` 可配置 `appId`、`endpoint`、插件开关和隐私策略。 | 低 |
| SDK 销毁 | P0 | 开启 | `sdk.destroy` 后移除监听、计时器、patch 和队列任务。 | 中 |
| 插件注册 | P0 | 开启 | `sdk.use(plugin)` 支持幂等注册和异常隔离。 | 中 |
| 自定义事件 | P0 | 开启 | `sdk.track(name, props)` 生成标准事件并进入队列。 | 低 |
| 公共属性 | P0 | 开启 | `register` 和 `unregister` 生效，且不能覆盖 SDK 内置字段。 | 低 |
| 手动 flush | P0 | 开启 | `sdk.flush()` 主动发送当前队列并返回发送结果。 | 中 |
| debug 日志 | P1 | 关闭 | 开启后打印关键生命周期和发送状态，不输出敏感值。 | 低 |

## 3. 身份与会话

| 功能 | 优先级 | 默认状态 | 验收标准 | 风险 |
| --- | --- | --- | --- | --- |
| `distinct_id` | P0 | 开启 | 首次访问生成并持久化，刷新页面保持不变。 | 低 |
| `session_id` | P0 | 开启 | 30 分钟无活动后更新，活动期间保持不变。 | 中 |
| `user_id` | P0 | 手动 | `login` 写入，`logout` 清除，不影响 `distinct_id`。 | 低 |
| 跨标签页会话同步 | P2 | 关闭 | 多标签页可共享 session 状态。 | 中 |

## 4. 行为采集

| 功能 | 优先级 | 默认状态 | 验收标准 | 风险 |
| --- | --- | --- | --- | --- |
| 页面访问 | P0 | 开启 | 初始化和路由变化生成 `$pageview`。 | 低 |
| 页面离开 | P0 | 开启 | 页面隐藏或离开时生成 `$pageleave`，包含停留时长。 | 中 |
| SPA 路由监听 | P0 | 开启 | 支持 `pushState`、`replaceState`、`popstate`。 | 中 |
| 点击采集 | P1 | 关闭 | 点击声明元素后生成 `$click`，默认不采集输入值。 | 高 |
| 曝光采集 | P1 | 关闭 | 元素可见超过阈值和时间后生成 `$exposure`。 | 中 |
| 转化采集 | P1 | 手动 | 业务调用 `sdk.conversion` 后生成 `$conversion`。 | 中 |
| 录屏回放 | P1 | 关闭 | 开启后生成 `$replay_start`、`$replay_chunk`、`$replay_end`。 | 高 |
| 热力图 | P1 | 关闭 | 开启后生成点击、滚动、曝光热力图聚合事件。 | 高 |
| 表单采集 | P2 | 关闭 | 仅采集提交事件和表单标识，不采集字段值。 | 高 |

## 5. 运营侧采集

| 功能 | 优先级 | 默认状态 | 验收标准 | 风险 |
| --- | --- | --- | --- | --- |
| 运营采集域 | P0 | 开启 | 行为和转化事件包含 `domain: "operation"`。 | 低 |
| 渠道属性 | P1 | 手动 | `channel` 可通过 `register` 注入并进入运营事件。 | 低 |
| 活动属性 | P1 | 手动 | `campaign_id` 可用于活动效果聚合。 | 低 |
| 实验属性 | P1 | 手动 | `experiment_id` 可用于 AB 分组分析。 | 低 |
| 声明式点击 | P1 | 关闭 | 支持 `data-track-id`、`data-track-name`、`data-track-area`。 | 中 |
| 声明式曝光 | P1 | 关闭 | 支持 `data-exposure-id`、`data-exposure-name`、`data-exposure-area`。 | 中 |
| 漏斗事件 | P1 | 手动 | 关键步骤可通过自定义事件或 `$conversion` 统一分析。 | 中 |
| 录屏抽样 | P1 | 关闭 | 支持 `replay.sampleRate`，默认不超过 1%。 | 高 |
| 录屏分片 | P1 | 关闭 | 录屏数据按 `rid + seq` 拆成 `aly.gif` 分片上传。 | 高 |
| 热力图本地聚合 | P1 | 关闭 | 点击和滚动数据本地聚合为稀疏矩阵后上传。 | 中 |
| 点击率口径 | P1 | 文档 | 可按 `$click / $exposure` 计算入口点击率。 | 低 |
| 转化率口径 | P1 | 文档 | 可按 `$conversion / 漏斗起点事件` 计算转化率。 | 低 |

## 6. 异常监控

| 功能 | 优先级 | 默认状态 | 验收标准 | 风险 |
| --- | --- | --- | --- | --- |
| JS Error | P0 | 开启 | 捕获同步运行时错误，包含 message、stack、filename、行列号。 | 中 |
| Promise Error | P0 | 开启 | 捕获未处理 Promise rejection。 | 中 |
| Resource Error | P1 | 开启 | 捕获脚本、样式、图片等资源加载失败。 | 中 |
| SDK 内部错误隔离 | P0 | 开启 | SDK 自身错误不影响宿主应用，不产生递归上报。 | 高 |
| Source Map 解析 | P2 | 关闭 | 服务端侧解析堆栈。 | 中 |

## 7. API 监控

| 功能 | 优先级 | 默认状态 | 验收标准 | 风险 |
| --- | --- | --- | --- | --- |
| `fetch` 监控 | P1 | 关闭 | 记录 URL、method、status、duration、success。 | 高 |
| `XMLHttpRequest` 监控 | P1 | 关闭 | 不破坏原始 XHR 行为，记录状态和耗时。 | 高 |
| 上报地址排除 | P1 | 开启 | SDK 自身采集接口不触发 API 监控。 | 高 |
| 请求体和响应体采集 | P2 | 关闭 | V1 不建议支持。 | 高 |
| URL 脱敏 | P1 | 开启 | query 中敏感参数被替换为 `[masked]`。 | 高 |

## 8. 性能监控

| 功能 | 优先级 | 默认状态 | 验收标准 | 风险 |
| --- | --- | --- | --- | --- |
| FCP | P1 | 开启 | 支持时生成对应性能事件。 | 中 |
| LCP | P1 | 开启 | 页面隐藏前 flush 最新 LCP。 | 中 |
| CLS | P1 | 开启 | 忽略用户输入后的合理布局变化。 | 中 |
| INP | P1 | 开启 | 支持浏览器上报，低版本自动跳过。 | 中 |
| TTFB | P1 | 开启 | 基于 Navigation Timing 计算。 | 低 |
| 路由级性能 | P2 | 关闭 | SPA 路由切换后计算软导航指标。 | 高 |

## 9. 开发者侧采集

| 功能 | 优先级 | 默认状态 | 验收标准 | 风险 |
| --- | --- | --- | --- | --- |
| 开发者采集域 | P0 | 开启 | 异常、API、性能和诊断事件包含 `domain: "developer"`。 | 低 |
| 发布版本属性 | P1 | 手动 | `release`、`build_id`、`git_sha` 可用于问题定位。 | 低 |
| 错误指纹 | P1 | 开启 | 异常事件生成稳定 `error_id`，便于聚合。 | 中 |
| API trace ID | P1 | 白名单 | 支持安全请求 ID，例如 `trace_id` 或 `request_id`。 | 中 |
| 性能评分 | P1 | 开启 | Web Vitals 输出 `good`、`needs-improvement`、`poor`。 | 低 |
| SDK 自诊断 | P1 | 开启 | 生成 `$sdk_diagnostic` 或 debug 日志，记录重试、丢弃、降级。 | 中 |
| 诊断限频 | P1 | 开启 | 同类诊断事件在故障风暴中不会无限上报。 | 高 |

## 10. 传输与缓存

| 功能 | 优先级 | 默认状态 | 验收标准 | 风险 |
| --- | --- | --- | --- | --- |
| 内存队列 | P0 | 开启 | 事件入队、批量出队、队列上限可配置。 | 中 |
| 像素队列 flush | P0 | 开启 | 达到条数或时间阈值后拆成多条 `aly.gif` 图片请求。 | 中 |
| Pixel GET 上报 | P0 | 开启 | 所有上传都通过 `GET /aly.gif?...` 图片请求上报。 | 中 |
| Pixel URL 限长 | P0 | 开启 | URL 超过阈值时删除低优先级字段、截断或丢弃。 | 中 |
| 离场像素上报 | P1 | 开启 | 页面离开前尽量提前触发像素请求，不等待响应。 | 中 |
| 失败重试 | P0 | 开启 | 图片 `error`、超时或网络离线时按退避重试。 | 中 |
| 离线缓存 | P0 | 开启 | 离线或连续失败时写入本地缓存。 | 中 |
| 网络恢复补发 | P0 | 开启 | `online` 后读取缓存并补发。 | 中 |
| 幂等批次 ID | P1 | 开启 | 每批数据携带 `batch_id`。 | 低 |

## 11. 隐私与安全

| 功能 | 优先级 | 默认状态 | 验收标准 | 风险 |
| --- | --- | --- | --- | --- |
| URL query 脱敏 | P0 | 开启 | 敏感参数不以明文进入队列。 | 高 |
| 输入值禁止采集 | P0 | 开启 | `input`、`textarea`、`select` 的真实值不采集。 | 高 |
| Cookie 禁止采集 | P0 | 开启 | SDK 不读取、不发送 Cookie 内容。 | 高 |
| 请求体和响应体禁止采集 | P0 | 开启 | API 监控只采元数据。 | 高 |
| 录屏文本遮罩 | P0 | 开启 | 录屏默认遮罩页面文本和输入值。 | 高 |
| 录屏节点屏蔽 | P1 | 开启 | 支持 `maskSelectors` 和 `blockSelectors`。 | 高 |
| `beforeSend` | P1 | 开启 | 业务可最终修改或丢弃事件。 | 中 |
| consent 授权 | P1 | 开启 | 用户未授权时不采集、不发送。 | 高 |

## 13. V1 验收清单

- [ ] 初始化后自动生成 `distinct_id` 和 `session_id`。
- [ ] `track` 事件可进入队列并上报。
- [ ] 页面访问和 SPA 路由变化可上报 `$pageview`。
- [ ] 页面离开可尝试上报 `$pageleave`。
- [ ] JS Error 和 Promise Error 可上报。
- [ ] 队列 flush 按条数和时间触发，并拆成像素请求。
- [ ] 所有上传都通过 `GET /aly.gif?...` 上报。
- [ ] Pixel GET 请求表现为图片资源请求并带防缓存参数。
- [ ] Pixel URL 超长时会截断、摘要化或丢弃，不切换其他上传方式。
- [ ] 网络失败后可重试。
- [ ] 离线事件可写入缓存并在恢复后补发。
- [ ] 默认不采集输入框值、Cookie、请求体、响应体。
- [ ] URL query 敏感参数会脱敏。
- [ ] 插件可独立开启、关闭和销毁。
- [ ] 核心包 gzip 体积符合目标。
- [ ] 运营侧事件可按 `domain = operation` 独立查询。
- [ ] 开发者侧事件可按 `domain = developer` 独立查询。
- [ ] `$conversion` 可用于运营转化分析。
- [ ] 录屏默认关闭，开启后可生成分片并通过 `aly.gif` 上传。
- [ ] 热力图默认关闭，开启后可本地聚合并通过 `aly.gif` 上传。
- [ ] 录屏和热力图不采集输入框真实值、Cookie、Token、请求体、响应体。
- [ ] `$sdk_diagnostic` 可用于开发者排障且具备限频策略。
